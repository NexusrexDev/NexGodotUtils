# Nex's Godot Utils
An exercise in building modular systems in Godot 4, wrapping them into add-ons and storing them to save time and for future use.

## Currently implemented systems
- Audio Manager
    An autoload singleton that wraps music, SFX (Spatial -2D/3D- and Nonspatial), UI sounds and voicelines behind a simple API, along with automatic bus setup.
